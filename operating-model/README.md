# Operating Model (3.1)

Templates for **Phase 0** of The AppSec Program Playbook: chartering the program,
recording decisions, and accepting risk with an expiry date.

| File | Use it for |
|---|---|
| [`charter-template.md`](charter-template.md) | The one-page program charter: scope, who owns what, decision rights |
| [`decision-record-template.md`](decision-record-template.md) | Program decision records (PDRs) with a revisit date, plus a worked example |
| [`exception-register/`](exception-register/) | Accepted risks as files in Git, with approvals by priority and an automatic expiry check |
